# NextBites

A responsive recipe home page built with Next.js, TypeScript, and the App Router.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to browse the recipe grid.

## Project structure

- `app/data/recipes.ts` contains the typed recipe data.
- `app/components/RecipeCard.tsx` renders an individual recipe.
- `app/components/NavBar.tsx` provides shared site navigation.
- `app/page.tsx` maps the recipes into the responsive home-page grid.
